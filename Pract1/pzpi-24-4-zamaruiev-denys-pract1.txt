3 ОПИС ВИКОНАНОЇ РОБОТИ
Під час виконання практичного завдання було проаналізовано офіційні стандарти написання коду для мови програмування Kotlin, розроблені компанією JetBrains. Kotlin створювалася як безпечна та лаконічна альтернатива Java, тому основний фокус її конвенцій спрямовано на усунення типових вразливостей, таких як NullPointerException, та забезпечення імутабельності даних.

Основні розглянуті правила:
1. Осмислені назви змінних. Використання замість абстрактних чи однолітерних назв на користь самодокументованих змінних.
2. Імутабельність. Використання ключового слова val замість var. Це гарантує незмінність стану об’єктів після їх ініціалізації, що особливо критично у багатопотоковому середовищі.
3. Безпечна робота з Null. Категорично заборонено використання примусового розпакування. Замість нього застосовуються безпечні виклики у комбінації з оператором Елвіса для встановлення значень за замовчуванням або випереджувального виходу.
4. Функції розширення. Замість застарілих Java-утиліт використовуються ідіоматичні функції розширення, що дозволяє інтуїтивно викликати методи прямо на об’єктах.
5. Уникнення неявних чисел. Будь-які жорстко закодовані значення в логіці винесяться в іменовані константи.

До всіх наведених праил було наведено приклади у вигляді фрагментів коду. Було створено скрипт code-examples-code-conventions.kt, який демонструє порівняння старого та нового варіантів коду.

4 ВИСНОВКИ
У результаті виконання практичного завдання було розглянуто ключові концепції та стандарти написання чистого коду мовою Kotlin, розроблені JetBrains. Отримано навички трансформації небезпечного та застарілого Java-стилю програмування на сучасний, ідіоматичний та безпечний Kotlin-код. Здійснено практичний рефакторинг логіки прикладі коду з усуненням ризиків NullPointerException та неконтрольованої зміни стану. Підготовлено презентаційні матеріали та відеозвіт, що підтверджують розуміння принципів самодокументованого коду.

// Поганий приклад
fun process(u: User?){
    var status = u!!.getStatus()
    if (status == 1){
        println(u.getName() + " is active")
    }
}
// Після рефакторингу
const val STATUS_ACTIVE = 1

fun processUser(user: User?){
    val status = user?.status ?: return
    if (status == STATUS_ACTIVE){
        println("${user.name} is active")
    }
}
