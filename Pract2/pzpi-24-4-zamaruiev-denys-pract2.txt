3 ОПИС ВИКОНАНОЇ РОБОТИ
Під час виконання практичного завдання було проаналізовано вихідний код власного програмного проєкту написаного на Java зі Spring Boot)та виявлено архітектурні недоліки. Для покращення читабельності та розширюваності коду було застосовано три методи рефакторингу:
1. Метод «Replace Error Code with Exception»
Опис проблеми: У вихідному коді метод getCarTrim повертав null у разі відсутності запису в базі даних. Це змушувало контролери постійно дублювати перевірки та приховувало справжню причину помилки.
Переваги: Метод тепер викидає IllegalArgumentException, який обробляється глобальним хендлером Spring.
2. Метод «Separate Query from Modifier»
Опис проблеми: Метод saveConfiguration порушував принцип CQS. Він одночасно діяв як модифікатор і як запит. Це робило метод непередбачуваним.
Переваги: Логіку розділено. Тепер команда saveConfiguration лише зберігає дані та повертає ідентифікатор, а читання даних делеговано ізольованому запиту getByShareCode.
3. Метод «Replace Method with Method Object»
Опис проблеми: Алгоритм calculatePrice був громіздким та містив безліч тимчасових змінних. Розбити його на підметоди було неможливо через необхідність передавати велику кількість параметрів.
Переваги: Логіку винесено в окремий клас PriceCalculator, де тимчасові змінні стали полями. Це дозволило розбити складний метод на зрозумілі приватні підметоди.
4 ВИСНОВКИ
У результаті виконання практичного завдання було розглянуто ключові методи покращення архітектури ПЗ за Мартіном Фаулером. Отримано навички виявлення проблем у власному Java-коді. Успішно застосовано методи Replace Error Code with Exception, Separate Query from Modifier та Replace Method with Method Object, що зробило код безпечнішим, чистішим та готовим до масштабування. Підготовлено презентаційні матеріали та відеозвіт, що підтверджують ефективність застосованих методів.

// ДО РЕФАКТОРИНГУ (Поганий код - громіздкий метод)
public PriceResponse calculatePriceBad(PriceRequest request) {
    CarTrim trim = carTrimRepository.findById(request.getTrimId()).orElseThrow();
    BigDecimal basePrice = trim.getCarModel().getBasePrice().add(trim.getPriceModifier());
    List<Option> options = request.getSelectedOptionIds() != null 
            ? optionRepository.findAllById(request.getSelectedOptionIds()) 
            : Collections.emptyList();
    BigDecimal optionsCost = options.stream()
            .map(Option::getPriceModifier)
            .reduce(BigDecimal.ZERO, BigDecimal::add)
    BigDecimal discount = BigDecimal.ZERO;
    BigDecimal totalPrice = basePrice.add(optionsCost).subtract(discount);
    return new PriceResponse(basePrice, optionsCost, discount, totalPrice);
}
// ПІСЛЯ РЕФАКТОРИНГУ (Гарний код - винесення в об'єкт)
public PriceResponse calculatePriceGood(PriceRequest request) {
    return new PriceCalculator(carTrimRepository, optionRepository, request).compute();
}
public class PriceCalculator {
    private final CarTrimRepository carTrimRepository;
    private final OptionRepository optionRepository;
    private final PriceRequest request;
    private BigDecimal basePrice;
    private BigDecimal optionsCost;
    private BigDecimal discount = BigDecimal.ZERO;
    public PriceCalculator(CarTrimRepository carTrimRepository, OptionRepository optionRepository, PriceRequest request) {
        this.carTrimRepository = carTrimRepository;
        this.optionRepository = optionRepository;
        this.request = request;
    }
    public PriceResponse compute() {
        calculateBasePrice();
        calculateOptionsCost();       
        BigDecimal totalPrice = basePrice.add(optionsCost).subtract(discount);
        return new PriceResponse(basePrice, optionsCost, discount, totalPrice);
    }
    private void calculateBasePrice() {
        CarTrim trim = carTrimRepository.findById(request.getTrimId()).orElseThrow();
        basePrice = trim.getCarModel().getBasePrice().add(trim.getPriceModifier());
    }
    private void calculateOptionsCost() {
        List<Option> options = request.getSelectedOptionIds() != null 
                ? optionRepository.findAllById(request.getSelectedOptionIds()) 
                : Collections.emptyList();
        optionsCost = options.stream()
                .map(Option::getPriceModifier)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
    }
}
